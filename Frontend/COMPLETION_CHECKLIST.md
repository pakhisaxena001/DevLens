## 📝 Notes for Developers

### Getting Started
```bash
cd Frontend
npm install
npm run dev
```

### File Structure
- Pages in `src/pages/`
- Stores in `src/stores/`
- Components in `src/components/`
- Routes in `src/router/index.js`

### Key Configuration Files
- `vite.config.js` - Vite configuration
- `tailwind.config.js` - Tailwind setup (auto-configured)
- `package.json` - Dependencies and scripts

### API Integration
Replace TODO comments and mock data with actual API endpoints:
- Search for `// TODO: Call API` comments
- Replace mock data in stores with API calls
- Add proper error handling

### Extending the Application
1. Add new pages in `src/pages/`
2. Add new stores in `src/stores/` if needed
3. Create reusable components in `src/components/`
4. Add new routes to `src/router/index.js`
5. Use existing components as templates
